讨论与记录日期：2026-11-13。状态：阶段性讨论暂存，供继续完善。

## 本日最重要的结论

1. 原规划多数条目已完成，可关闭；旧规划作为背景，不要求逐项继承。
2. 新矩阵立足已有服务接口、组织管理、交付和平台方案基础，面向 VCC 等团队的车控 Agent 目标重新规划。
3. 矩阵定位为虚拟 COE，负责共同能力、架构原则、方法、技术共识和知识资产，没有强项目交付属性。
4. VCC 对其承接的 Mission 负责；系统产品对本域能力和执行负责；矩阵组织共同技术能力建设。
5. SO、FO、AI、平台及领域软件架构师、SWE 应形成贯通功能、系统、车型与软件实现的协作机制。
6. DO 按议题参与交付衔接；TPM 支撑技术组织运营，不将全部研究工作转化为车型节点管理。
7. 技术共识、业务承诺、车型架构决策和工程交付承诺分别由相应责任主体确认。
8. 以真实业务问题牵引，沉淀可复用的契约、模式、样例、验证方法和工具能力，并持续获取应用反馈。
