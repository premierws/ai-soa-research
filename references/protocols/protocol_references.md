# MCP 与 A2A 参考链接

以下是昨日协议讨论涉及的官方来源。当前保存来源链接和研究边界，未保存完整网页，也未重新核验其是否发生变更。

- [MCP Tools 规范](https://modelcontextprotocol.io/specification/2026-07-28/server/tools)：用于了解能力发现、结构化工具输入输出与交互机制。
- [MCP 架构说明](https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture)：用于区分业务能力与工具访问层。
- [A2A 与 MCP 的关系](https://a2a-protocol.org/v0.3.0/topics/a2a-and-mcp/)：用于讨论工具访问和独立 Agent 协作的不同关注点。
- [A2A 规范](https://a2a-protocol.org/v0.3.0/specification/)：作为委托、任务协作和生命周期表达的可选参考。

本次研究没有决定采用哪一种协议。不能因为使用 MCP 就省略权限、目标完成和 Mission 语义；也不能仅因为两端都叫 Agent 就认定必须使用 A2A。

正式评估技术方案时，需要重新核对选定版本的规范、实现和约束。这里的链接是研究来源线索，不是依赖锁定清单。
