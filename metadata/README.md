# 归档元数据

- `source_manifest.json`：复制材料的来源路径、原始来源 URL（如有）、源仓库 HEAD、选定文件工作区状态、长度和 SHA-256。
- `archive_manifest.json`：本项目归档文件清单与指纹，用于核对后续拷贝是否完整。清单本身及会被重新生成的验证结果不参与自校验。
- `evidence_locators.json`：16 个关键原文摘录在本地快照中的行号。
- `verification_result.json`：最近一次归档验证的结果。

原始文件复制后不改写。新增的关键结论、研究脉络、证据表与索引属于本次整理内容，依据为昨天的完整报告、用户对话和归档材料。

2026-11-13 新增 `docs/organization/` 分层组织专题，并将两份原组织规划正文及三张关键白板响应加入来源清单。讨论记录为结构化复盘，不是逐字聊天导出；该专题为阶段性暂存，不代表正式章程或工程承诺。

用户提供的行业正文由对话转存为 Markdown；其来源是用户输入，不是成功抓取到的微信网页。接口示例直接从昨日完整报告的代码块提取。

具体以 `source_manifest.json` 中逐文件记录为准。HEAD 只标识仓库提交；选定文件若存在工作区差异，应同时检查 `working_tree_status`，不能只依赖 HEAD 判断其内容。

归档未保存认证环境、账号凭据或原始认证响应，也没有把抓取失败的空文件和环境验证页面当作正文。
